## 怎么读

- **占官方价** = 分组倍率 × 充值汇率（¥ 买站内 $1）÷ 6.8。5% 就是官方价的 5%。**≥** 表示套餐/预付卡，额度跑满才到这个数。
- **站上倍率**：站点自己写的原文，你在它令牌分组下拉框里要选的那个。跟占官方价对不上，以站点为准。
- **档位**：站点给这一档起的名字和描述，原文照抄。
- **核价日**：我们最后一次登录这家核价的日期。价格会变，以站点当前为准。
- 每家只列最便宜的一档，按占官方价从低到高排。每家每一档见网页版的详情页。
- 只比价格。号池真假、稳定性、会不会跑路不测、不评。
